# 🪨📄✂️ Rock Paper Scissors Game (JavaScript)

A simple browser-based **Rock-Paper-Scissors** game built with **vanilla JavaScript**.  
This project demonstrates my understanding of **functions, conditionals, loops, randomization, and state management** — all core programming concepts.

---

## 🎯 Project Overview
The game allows a human player to compete against the computer.  
Each round compares the player’s choice with a randomly generated computer choice, updates the scores, and declares a winner after five rounds.

---

## 🧠 Features
- Random computer choice using `Math.random()`
- Case-insensitive player input via `prompt()`
- Score tracking across rounds
- Dynamic winner messages for each round
- Final game result after three rounds

---

## 🧩 Technologies Used
- **HTML5** – for structure  
- **JavaScript (ES6)** – for game logic and interactivity  

---

## 🕹️ How to Play
1. Open the game in your browser.  
2. Enter your choice: `rock`, `paper`, or `scissors`.  
3. The computer randomly selects its move.  
4. The console displays the round result and final winner after three rounds.
